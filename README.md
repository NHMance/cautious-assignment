## 빠른 시작 (공통)

각 주차 폴더는 독립된 Python 프로젝트입니다. 자세한 순서는 그 주차 README 의 「2. 실행 방법」을 따릅니다.

```bash
# 1) 도구 설치 (최초 1회) — Python 3.11+ 과 uv
brew install uv                      # macOS. Windows 는 https://docs.astral.sh/uv/ 안내

# 2) 주차 폴더에서 의존성 설치·테스트
cd week02
uv sync
uv run pytest

# 3) 인증 정보 (최초 1회) — 국내 모의 APP Key·Secret. 둘 중 하나 (환경변수가 우선)
#   방법 1. 환경변수 / .env
cp .env.example .env                 # 열어서 NH_PAPER_APP_KEY, NH_PAPER_APP_SECRET 입력
#   방법 2. 저장소 밖 설정 파일
#   ~/NHFutures/config/config.yaml 에 입력 (형식은 week02/README.md 2-2절)
```

- 실행하면 첫 줄에 `인증 정보: env` 또는 `인증 정보: config.yaml` 로 어느 쪽을 읽었는지 나옵니다.
- 환경변수로는 **모의(paper) 키만** 받습니다. 실전 키를 넣는 자리가 없어 이 방법으로는 실전 주문이 나갈 수 없습니다.
- `.env` 는 `.gitignore` 에 있어 Git 에 올라가지 않지만, 주차 폴더 **안에** 있으므로 커밋 전 `git status` 에 `.env` 가 없는지 확인합니다.
- 인증 서버에서 받은 토큰은 `~/NHFutures/config/tokens.json` 에 저장됩니다. 이 폴더는 저장소 밖입니다.

## 기록 시 주의사항

- **인증정보를 올리지 않습니다.** APP Key, Secret Key, 토큰, 계좌번호·비밀번호와 개인 설정 파일(`.env`, `config.yaml`)은 저장소에 넣지 않습니다.
  봇의 기록(`results/*.jsonl`)은 계좌번호·계좌명·주문자 ID·접속 IP 칸을 `***` 로 지우고 씁니다. 화면 캡처의 계좌 식별정보도 가립니다.
- **실행 환경을 구분합니다.** 리플레이(지난 하루 실제 데이터), 봇 테스트(저장된 응답), DRY_RUN(주문 없이 기록만), 모의계좌 주문을 섞지 않고 어느 것인지 적습니다.
  기록의 `RUN_START.environment`·`dry_run` 칸으로 구분되며, `summarize.py` 는 리플레이·봇 테스트 기록을 기본으로 빼고 셉니다.
- **꾸미지 않습니다.** 주문 접수와 실제 체결을 구분하고(`ORDER_SUBMIT` ≠ `FILL`), 실행하지 않은 수치나 성공 여부를 만들지 않습니다. 손실 결과도 그대로 적고 분석합니다.
