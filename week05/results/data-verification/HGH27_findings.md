# HGH27 봉 미반환 검증

2026-11-19 NH 해외 모의 REST API에서 2026-11-02~13 평일 09:00~23:45 KST의 5분 구간 1,770개를 재검증했다.

| 대조 항목 | 결과 |
| --- | ---: |
| 반환된 5분봉 | 1,297개 |
| 반환되지 않은 5분 구간 | 473개, 26.72% |
| 빈 구간에 거래량이 있는 1분봉이 존재 | 0개 |
| 빈 구간에 1분봉도 없음 | 473개 |
| 반환된 5분봉에 대응하는 1분봉이 없음 | 0개 |
| 5분봉 거래량과 구간 내 1분봉 거래량 합계 불일치 | 0개 |

1분봉 이어받기 19페이지에서 기준 기간 레코드 5,493개를 확보했다. 5분봉 재조회 결과도 기존 수집본의 개수와 일치했다.

모든 빈 구간에 1분봉도 없고 모든 반환 구간의 거래량 합계가 일치하므로, 체결이 있는 구간에만 봉을 만드는 처리와 일치한다. 무거래 구간 생략이 유력한 설명이다. 확인한 NH 공개 SDK 문서에는 무거래 구간의 봉 생성 규칙이 명시돼 있지 않았다. 동일 공급자의 자료끼리 대조했으므로 거래소 원본의 무거래 여부까지 독립 검증한 결과는 아니다.

26.72%는 예상 시간 격자에서 봉이 반환되지 않은 비율이다. 공급자 장애로 확정된 누락률로 해석할 수 없다.

대조 자료는 `HGH27_gap_reconciliation.csv`, 1분봉 시각·거래량은 `HGH27_1m_baseline.csv`, 집계는 `HGH27_summary.json`에 저장했다.
