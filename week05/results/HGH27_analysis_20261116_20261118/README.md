# HGH27 국면별 전략 분석 데이터

상품은 표준 구리선물 2027년 3월물 HGH27이다. 5분봉 가격 최소단위는 0.0005, 계약당 틱 가치는 $12.50이다. 수수료는 $0, 기본 슬리피지는 편도 1틱이다. 왕복 비용 가정은 $25다.

## 분석 구간과 국면 기준

기준 구간은 2026-11-02~13 KST, 시뮬레이션 구간은 완료된 2026-11-16~18 KST다. 기준 구간의 반환 봉 2,046개로 지표를 순서대로 계산했다. 초기 지표 계산에 필요한 관측치가 부족한 칸은 비어 있다. 분위수는 빈칸을 제외하고 선형 보간 방식으로 산출했다.

| 기준 | 산출 방법 | 값 |
| --- | --- | ---: |
| ER_lo | 기준 ER 30분위수 | 0.12043777203053647 |
| ER_hi | 기준 ER 70분위수 | 0.3038864415075882 |
| RV_hi | 기준 상대 ATR 90분위수 | 1.3655744959219942 |
| 거래당 손실 예산 | 기준 손절금액 80분위수 + 왕복비용, $5 단위 올림 | $350 |
| 일일 손실 한도 | 거래당 손실 예산 × 3 | $1,050 |

상대 ATR은 현재 ATR을 기준 구간 동일 KST 30분 시간대의 ATR 중앙값으로 나눈 값이다. 상대 ATR이 RV_hi 이상이면 HIGH_VOL, 이후 ER이 ER_hi 이상이면 TREND, ER_lo 이하이면 RANGE, 그 외는 NEUTRAL로 분류한다. C는 TREND에서 A, RANGE에서 B의 규칙을 사용한다.

## 파일 사용

| 파일 | 분석 내용 |
| --- | --- |
| baseline_20261102_20261113.csv | 기준 OHLCV, EMA, ATR, ER, Z-score, 상대 ATR, 시간대별 기준 ATR 중앙값 |
| thresholds.json | 사용 월물, 고정 임계값, 손실 예산, 기준값 확정 시각 |
| bars.csv | 시뮬레이션 705봉의 OHLCV·지표·국면 |
| summary.csv | 전략별 전체·진입 국면별 순손익, 거래 수, 승률, 실현손익 MDD, 평균 손익, 보류 수 |
| daily_summary.csv | 날짜별 전략별 성과 |
| trades_A.csv, trades_B.csv, trades_C.csv | A/B/C 각각의 체결 내역 |
| trades.csv | 추가 비교 전략까지 포함한 전체 체결 내역 |
| holds.csv | 신규 진입 신호가 보류된 시각·방향·사유 |
| signal_analysis.csv | 국면별 12봉 후 방향조정 가격변화/ATR의 평균·중앙값·양수 비율·표본 수 |
| sensitivity.csv | 편도 0~3틱 비용 재계산 및 전략 재실행 결과 |
| regimes.csv | 반환 봉 기준 국면별 봉 수와 5분 환산 시간 |
| open_positions.csv | 종료 시 미청산 포지션 |
| coverage-baseline.csv | 기준 구간 평일 09:00~23:45의 봉 반환 현황 |

신호 분석의 TREND는 EMA 방향, RANGE는 Z-score 반대 방향을 사용한다. RANGE의 적격 조건은 절대 Z-score 1.5 이상이다. eligible은 각 신호의 적격 표본, matched는 두 신호가 모두 적격인 동일 표본이다. all은 겹치는 미래수익 구간을 포함하고 nonoverlap은 12봉 간격 표본이다. 실제로 60분이 이어지는 12봉을 확보한 표본만 사용한다.

## 해석에 반영할 점

- 기준값은 2026-11-19에 확정됐다. 11/16~18 결과는 이미 지난 날짜의 회고 시뮬레이션이다. 기준값 계산에는 11/02~13 데이터만 사용했다.
- 무거래로 추정되는 구간에는 반환 봉이 없다. 지표는 반환된 봉을 차례로 사용하므로 ER(24)의 24구간이 항상 120분인 것은 아니다. 빈 봉을 새로 채우거나 기준값을 변경하지 않고 기존 구현으로 실행했다.
- 기준 구간 평일 분석 시간의 473개 빈 구간 모두에서 1분봉도 없었다. 26.72%는 봉 미반환 비율이며 공급자 장애로 확정된 누락률은 아니다. 별도 검증 자료는 상위 results/data-verification 폴더에 있다.
- regimes.csv의 분 단위 값은 반환 봉 수 × 5분이다. 반환되지 않은 시간의 국면은 포함하지 않는다.
- 과거 호가 자료가 없어 실시간 스프레드 필터를 재현하지 않았다. OHLCV 기반 가정 체결이며 MDD는 청산 실현손익 기준이다.
- C-1은 고변동성 차단을 해제한 비교, A-unlimited는 60분 보유 제한을 해제한 비교다.
