# 5주차 · 시장 국면별 전략 — COMEX 구리선물(HGH27) 추세추종·평균회귀

## 한눈에 보기

COMEX 구리선물 2027년 3월물(`HGH27`)의 확정 5분봉을 추세·횡보·고변동성·중립으로 분류하고, 시장 국면에 따라 전략을 선택하는 방식의 성과를 검증합니다.

- **전략** — A는 EMA 추세추종, B는 Z-score 평균회귀, C는 시장 국면에 따라 A·B 규칙을 선택합니다.
- **검증** — 10/19–23, 11/02–06, 11/16–18의 과거봉 리플레이에서 전략 성과와 편도 0–3틱 비용 민감도를 비교했습니다.
- **결과** — 기본 비용 기준 세 회차 합계에서 C만 +$2,475.00을 기록했습니다. NH 모의계좌에서는 HGH27 1계약의 주문·청산 기능을 검증했습니다.

## 1. 과제 요약

동일한 매매 전략이 모든 시장 상황에서 유효하지는 않다는 가설에서 출발했습니다. 구리선물 5분봉으로 시장 국면을 **추세·횡보·고변동성·중립**으로 분류하고, 국면에 맞는 전략을 고르는 **국면 적응형 전략(C)**이 한 가지 규칙만 쓰는 전략(A·B)보다 나은지 검증합니다.

| 항목 | 이번 구현 | 확인 상태 |
| --- | --- | --- |
| 대상 상품 | COMEX 구리선물 2027년 3월물 `HGH27` 1계약 | 마이크로 구리(`MHGH27`)에서 변경, 과정은 3-2절 |
| 국면 분류 | ER(24)·상대 ATR을 기준 기간 분위수와 비교 | 3회 검증 모두 기준 기간 자료로만 임계값 산출 |
| 전략 비교 | A 추세추종 · B 평균회귀 · C 국면 적응 | 과거 데이터 시뮬레이션 3회 완료 |

## 2. 실행 방법

저장소 루트에서 Python 3.11 이상과 `uv`를 사용합니다. NH 조회나 모의거래가 필요하면 `week05/.env.example`을 `week05/.env`로 복사하고 NH 해외선물 모의계좌 APP Key와 APP Secret을 설정합니다.

```powershell
uv run --project week05 python week05/main.py --help
uv run --project week05 python week05/main.py inspect --date 2026-11-13 --symbols HGH27
uv run --project week05 python week05/main.py quotes --seconds 300 --symbols HGH27
```

아래의 `STAMP`는 `inspect`로 확인한 `start` 또는 `end`로 교체합니다. 새 결과 경로에서 기준 기간과 검증 기간을 한 번에 수집합니다. 임계값 산출에는 기준 기간 봉만 사용합니다. `calibrate`는 해당 경로에 임계값이 있으면 종료합니다.

```powershell
uv run --project week05 python week05/main.py --results week05/results-local collect --bar-stamp STAMP --symbols HGH27 --first 2026-11-02 --last 2026-11-18
uv run --project week05 python week05/main.py --results week05/results-local calibrate --symbol HGH27 --selection-reason "표준 구리 3월물로 신호와 체결 통일"
uv run --project week05 python week05/main.py --results week05/results-local replay --exclude-date 2026-11-19
```

1·2회차는 `week05`에서 `uv run python -m copper.period_studies`로 재현합니다. `uv run python -m copper.dashboard`는 기본 경로의 저장된 리플레이 및 모의계좌 결과로 대시보드를 다시 만듭니다. 모의계좌에서 C를 실행하는 명령은 저장소 루트의 `uv run --project week05 python week05/main.py paper --bar-stamp STAMP`입니다. 시작 시 대상 월물의 잔고와 미체결 주문이 비어 있어야 합니다.

### 3-4. 지표와 국면 분류

| 지표 | 계산 | 의미 |
| --- | --- | --- |
| ER(24) | 24구간 순가격변동 절댓값 ÷ 구간별 변동 절댓값의 합 | 1에 가까울수록 한 방향, 0에 가까울수록 왕복 |
| ATR(14) | True Range의 14봉 Wilder 이동평균 | 변동 폭 |
| EMA(9, 21) | 지수이동평균 | 추세 방향 |
| Z-score(24) | (현재 종가 − 직전 24봉 평균) ÷ 직전 24봉 표본 표준편차 | 평균 대비 이탈 정도. 현재 봉 제외 |
| 상대 ATR | 현재 ATR ÷ 기준 기간 같은 KST 30분 구간의 ATR 중앙값 | 같은 시간대 평소 대비 변동성 |

시간대마다 평소 변동성이 다르기 때문에(예: 미국 장 시작 전후), 단순 ATR 대신 **같은 30분 구간의 평소 값과 비교한 상대 ATR**을 썼습니다.

| 우선순위 | 국면 | 판단 기준 | C의 대응 |
| --- | --- | --- | --- |
| 1 | 고변동성 `HIGH_VOL` | 상대 ATR ≥ RV_hi | 신규 진입 금지 |
| 2 | 추세 `TREND` | ER ≥ ER_hi | 추세추종(A 규칙) |
| 3 | 횡보 `RANGE` | ER ≤ ER_lo | 평균회귀(B 규칙) |
| 4 | 중립 `NEUTRAL` | 그 외 | 관망 |

임계값은 임의로 정하지 않고 **기준 기간 자료의 분포**에서 산출했습니다. ER_lo는 ER 30분위수, ER_hi는 ER 70분위수, RV_hi는 상대 ATR 90분위수입니다. 산출한 값은 시뮬레이션 기간 동안 바꾸지 않았습니다.

### 3-5. A/B/C 전략 규칙

| 전략 | 진입 | 청산 |
| --- | --- | --- |
| A · 고정 추세추종 | EMA9 > EMA21 매수, EMA9 < EMA21 매도 | 반대 방향 EMA 교차 |
| B · 고정 평균회귀 | Z ≤ −1.5 매수, Z ≥ +1.5 매도 | 매수 Z ≥ −0.25, 매도 Z ≤ +0.25 |
| C · 국면 적응 | 추세 국면에서 A 조건, 횡보 국면에서 B 조건 | 진입에 쓴 전략의 청산 규칙 유지 |
| C-1 (비교용) | C와 같되 고변동성 진입 차단 해제 | C와 동일 |
| A-unlimited (비교용) | A와 동일 | 60분 보유 제한만 해제 |

- 진입 조건이 직전 봉에서 거짓, 현재 봉에서 참으로 바뀔 때만 신호로 봅니다.
- 확정 시각에 시작하는 다음 5분봉의 시가로 진입합니다. 해당 시각의 봉이 비어 있으면 신호를 보류합니다.
- C는 진입 후 국면이 바뀌어도 처음 쓴 전략의 청산 규칙을 유지합니다.
- C는 EMA 교차 시점뿐 아니라, EMA 방향이 이미 형성된 상태에서 ER이 추세 기준에 도달하는 시점에도 진입할 수 있습니다. 따라서 C와 A의 차이에는 국면 선택 효과와 진입 시점 차이가 함께 섞여 있습니다.

### 3-7. 3회 이동 검증

처음 계획은 11/02–13을 기준으로 11/16–19를 한 번 검증하는 것이었습니다. 그러나 3일·10회 안팎의 거래로는 결과가 우연인지 판단하기 어려워, **기준 2주 → 이후 별도 기간 시뮬레이션**을 시기를 옮겨 3회 반복했습니다.

### 3-8. 비용 가정

| 항목 | 값 |
| --- | --- |
| 수수료 | $0 (실제 계좌 요율이 아닌 가정) |
| 기본 슬리피지 | 편도 1틱 = $12.50, 왕복 $25 |
| 민감도 분석 | 편도 0·1·2·3틱 (왕복 $0·$25·$50·$75) |

리플레이는 진입·청산 가격에 각각 편도 슬리피지를 반영합니다. 결과 JSON의 gross는 이 체결가의 차이로 계산한 손익이며, net은 gross에서 수수료만 차감합니다. slippage는 기준가 대비 비용을 보여 주는 항목입니다.

민감도는 두 가지 방식으로 계산했습니다.

- **비용 재계산**: 같은 거래 내역에 비용만 바꿔 다시 계산합니다. 비용 자체의 영향만 볼 수 있습니다.
- **전략 재실행**: 비용을 바꿔 전략을 다시 돌립니다. 비용이 커지면 손실 예산을 넘는 진입이 막혀 거래 수와 시점이 달라집니다.

- REST 재조회에서 최근 확정봉이 수정되면 지표 이력을 다시 계산하고 `BAR_RECONCILE`을 남깁니다. 주문 전후 대상 월물의 잔고·미체결을 대조하고, 주문 결과가 불명확하면 재주문을 잠급니다. 손절 체결 결과가 거래당 예산을 넘으면 `budget_exceeded`로 기록합니다.

#### Q1·Q2 봉 단위 신호 분석

신호가 둘 다 적격인 동일 봉(`matched`)에서 `(12봉 뒤 종가 − 현재 종가) × 신호 방향 ÷ 현재 ATR`을 비교했습니다. 12봉 뒤 시각과 60분 차이가 나는 표본을 사용했습니다. 추세추종 방향은 EMA9와 EMA21의 대소 관계, 평균회귀 방향은 절댓값 1.5 이상인 Z-score의 반대 방향입니다. 아래 셀은 평균 / 중앙값 / 양수 비율이며, 표본 수는 두 방향에 공통입니다.

| 회차 | 시장 국면 | 표본 수 | 추세추종 방향 | 평균회귀 방향 |
| --- | --- | ---: | --- | --- |
| 1회 | TREND | 21 | −1.720 / −2.082 / 28.6% | +1.720 / +2.082 / 66.7% |
| 2회 | TREND | 31 | +0.851 / +0.905 / 61.3% | −0.851 / −0.905 / 38.7% |
| 3회 | TREND | 22 | −1.333 / −0.319 / 36.4% | +1.333 / +0.319 / 63.6% |
| 1회 | RANGE | 8 | +1.478 / +1.331 / 62.5% | −1.478 / −1.331 / 37.5% |
| 2회 | RANGE | 5 | +0.922 / +2.205 / 60.0% | −1.100 / −2.205 / 20.0% |
| 3회 | RANGE | 26 | −0.381 / +0.007 / 50.0% | +0.503 / +0.388 / 57.7% |

수익률 구간의 중첩을 제거하면 TREND 표본 수는 3·7·1개, RANGE는 2·1·3개입니다. 1회차 TREND와 2회차 RANGE는 비중첩 표본에서 평균의 우위 방향이 뒤집혔습니다. 이 지표는 방향의 사후 가격 변화이며 거래비용과 청산 규칙을 적용한 손익은 6절에서 비교했습니다.

### 7-2. 국면 적응형 전략(C)의 성과

- **세 회차를 합치면 C만 수익**이었습니다(+$2,475.00). A와 B는 모두 누적 손실이었습니다.
- C는 손실 회차(2회)에서도 **손실 금액이 세 전략 중 가장 작았습니다**.
- 한 가지 규칙만 쓰는 전략은 장에 따라 성과가 크게 흔들렸습니다. B는 3회차에 1위(+$1,150.00)였지만 1·2회차에는 최하위였습니다. A는 세 번 모두 손실이었습니다.
- 기본 거래를 편도 3틱으로 재계산해도 C의 3회 합계는 수익(+$525.00)으로 남았습니다.

다만 **C의 누적 수익은 1회차(+$2,650.00)에 크게 의존**합니다. 1회차를 빼면 C의 합계는 −$175.00입니다. 다른 기간에서도 손익과 낙폭이 개선되는지 추가 검증이 필요합니다.

### 7-3. 비용이 손익에 미친 영향

4주차 스프레드 전략은 비용을 빼면 수익이었다가 1틱 비용에서 손실로 바뀌었습니다. 이번 A와 B는 1·2회차 모두 **비용 0틱에서도 손실**이었습니다(A −$1,137.50·−$600.00, B −$1,337.50·−$1,450.00). 두 회차에서는 비용을 제거해도 A·B의 기존 진입·청산 거래 합계가 적자였습니다. 반면 C는 1회차 비용 0틱 기준 거래당 평균 약 +$172로, 왕복 비용 $25를 충분히 넘었습니다.

### 7-4. 11/02–06의 고변동성

2회차 시뮬레이션 기간은 고변동성 봉이 37.33%로, 기준 기간(8.76%)과 성격이 크게 달랐습니다. 임계값은 직전 2주 분포로 정하므로, **변동성 수준 자체가 갑자기 바뀌면 국면 분류가 과거 기준에 맞춰져 시장을 제대로 반영하지 못할 수 있습니다**. 이 기간에 C는 고변동성 구간 진입을 막아 거래 수가 11회로 줄었습니다. 하지만 남은 거래의 승률이 27.27%여서 손실을 피하지 못했습니다. 고변동성 차단을 해제한 C-1의 순손익은 −$87.50이었습니다.

### 7-5. 검증 범위와 한계

- **표본 크기**: 13거래일, 전략별 35–50회 거래입니다. 통계적 유의성이나 장기 수익성을 판단하기에는 부족합니다.
- **검증 공백**: 10/26–30, 11/09–13은 시뮬레이션하지 않았습니다(기준 기간으로만 사용).
- **회고 시뮬레이션**: 세 검증 모두 11/19에 실행한 과거 재현입니다. 미래 자료를 임계값에 쓰지는 않았지만, 당시 실시간으로 운용한 성과와는 구분해야 합니다.
- **봉 미반환**: 기준 기간 시간 격자의 26.72%에서 봉이 반환되지 않았습니다. 1분봉 대조 결과 무거래로 추정했습니다. 빈 봉을 채우지 않았기 때문에 ER(24)의 24구간이 항상 120분을 뜻하지는 않습니다.
- **가정 체결**: 진입은 바로 다음 5분봉 시가를 기준으로 했습니다. 손절은 시가가 손절가를 넘겨 시작하면 시가를, 장중 고가·저가가 손절가에 닿으면 손절가를 기준으로 편도 슬리피지를 적용했습니다. 과거 호가가 없어 스프레드 필터(3틱), 주문 지연과 체결 여부는 모형에 반영하지 못했습니다.
- **비교의 섞임**: C는 ER 조건 변화로도 진입하므로, A와의 차이에는 국면 선택 효과와 진입 시점 차이가 함께 들어 있습니다.
- **고정 설정값**: EMA(9, 21), Z ±1.5 등은 초기 설정값이며 최적화하지 않았습니다.
- **실시간 미검증**: C 전략의 모의계좌 실시간 운용은 하지 못했습니다.
